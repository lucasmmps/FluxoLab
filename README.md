# FluxoLab

Ferramenta web para criação e resolução de fluxogramas em atividades educacionais.

## Arquivos do projeto

- `index.html`: interface do educador para preparar e editar atividades.
- `student-template.html`: modelo da interface destinada aos alunos.

## Como executar localmente

Abra `index.html` em um navegador moderno. O projeto foi desenvolvido para funcionar diretamente no navegador, sem etapa de compilação.

## Publicação

Este repositório pode ser publicado pelo GitHub Pages. Depois de adicionar os arquivos HTML à raiz, acesse **Settings → Pages**, selecione **Deploy from a branch**, escolha a branch `main` e a pasta `/(root)`, e salve.
